01 — Background

Background Information

In response to the evolving landscape of education and the increasing demand for innovative learning experiences, SUN Education is embarking on a mission to create an impactful and transformative Education Event. This initiative is fueled by the recognition that traditional education models are being reshaped by technology, changing student needs, and a growing appetite for lifelong learning.

So therefore it is necessary to have a platform that provides options on how to make it easier for them to search for an event and be able to register for the event without having to come directly to the venue so that information regarding education between teachers and students can be provided properly and correctly.

Goals

Create a website that can be accessed on computers and mobile and displays a list of events that will be held along with information about the event such as event theme, day, date, time — and users can register for the event easily.

03 — Define

Competitive Analysis

Competitive analysis is carried out to examine the features, strengths, weaknesses and reviews of competitor applications from customers. The goal is to find out the main features of this app with the aim of replicating or making the features better and to avoid the design mistakes they make.

ICAN Education Consultant
Strength
  • There are testimonials that make users more trustworthy.
  • Makes it easier for users to search for online or offline events because it has divided the types of events.
  • Displays information regarding the expo.
  • Easy to register for an event.
  • When registering there is suggested information which makes it easier for users to register.
Weakness
  • There is no explanation regarding what the event is held for — whether for consultation or just for talking and sharing.
  • Information about where and when the event will be held is less visible.
  • Only displays the 3 closest events, does not display events that will be held in the future.
IDP International Education Specialists
Strength
  • Provide information about what events will be held in that month and what events have already been held.
  • Provide information that in some events, the theme of the event is for which country.
  • Provides access to communicate with the company if the user wants to consult.
Weakness
  • Cannot register for the event via the website.
  • The event that will be held is not told whether the event is an online or offline event.
Synthesis

Affinity Mapping

I wrote down all the responses in miro and started grouping them by topic. From these insights, I was able to determine their needs.

Information Needs

Need information regarding the place, date, day and time of the event.
Need information about the event theme, place, day and time of the event.
Need information on the name of the event, place, date, day, time of the event, and what the theme of the event is.
Need information about whether there is a price to enter the event, collaboration with any universities, schedule, information about the event organizer and a telephone number that can be contacted.
